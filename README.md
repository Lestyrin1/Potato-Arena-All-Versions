_quick read:_

In this repository, you will find all versions of Potato Arena (on Roblox)

You are allowed to take any assets I made, and any code I've written, and use them in your roblox game, so long as you credit me.

Do note that you may find a large abundance of assets from the toolbox, especially in older versions.

Each time I publish an update, I may sometimes (or frequently) forget to upload its version here, expect the version file to appear only days, or possibly even weeks after I publish an update. (Unless someone reminds me ofcourse)



_more details:_

**__What should you expect in these files/versions?__**

- In older versions, expect a LOT of spaghetti code, expect some traces of spaghetti code in the NEWER versions too!
- Data/Stat Management can differ WILDLY between versions, Just because one version manages stats in a ModuleScript, doesn't mean every other version will too, keep that in mind if you're editing stats!
- DataStorage will not work with any of the files, this is turned off by default in Roblox Studio, you have to turn it on manually in the settings for them to work.

Oh, and also, if you find any bugs in an older version, please do not reach out to me to fix specific versions, this is to preserve how the game actually worked during those times. (I'm sure most of you know this, but that's just a heads up.)
